# Phase 2 -- UI Design Contract

> Visual and interaction contract for the Content and Pages phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (SvelteKit -- shadcn not applicable) |
| Preset | not applicable |
| Component library | none (custom Svelte 5 components) |
| Icon library | inline SVG (hand-written, established in Phase 1) |
| Font | Satoshi (headings), Inter Variable (body), Geist (accent/UI), Fragment Mono (code) |

Source: Phase 1 codebase -- `src/app.css` @theme block, existing components.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, reading-time metadata spacing |
| sm | 8px | Compact element spacing, tag/badge padding |
| md | 16px | Default element spacing, card internal gaps, paragraph margin-bottom |
| lg | 24px | Section internal padding, grid gaps between cards |
| xl | 32px | Card padding (p-8), content column gaps |
| 2xl | 48px | Section vertical padding on mobile (py-12) |
| 3xl | 64px | Section vertical padding on desktop (py-16, md:py-24), page top/bottom |

Exceptions:
- Blog/case prose column: max-w-3xl (48rem / 768px) centered, narrower than the standard max-w-7xl container
- Service page hero: matches homepage hero padding (pt-20 md:pt-28 lg:pt-36)
- Legal page prose column: max-w-4xl (56rem / 896px) centered

## Page Templates

### Blog Post Page (`/blogs/[slug]`)

Layout from top to bottom:
1. **Date** -- `text-sm font-medium text-brand-purple` centered above the title
2. **Title (h1)** -- Display size, centered, max-w-4xl
3. **Hero image** -- full-width within max-w-3xl, rounded-xl, bg-brand-gold for image container
4. **Author row** -- avatar (40px circle) + "Door: [Name]" left-aligned, below hero image, mb-8
5. **Reading time badge** -- `text-sm text-brand-gray-dark` next to author name, separated by a middle dot
6. **Prose body** -- max-w-3xl mx-auto, Markdown-rendered content with prose typography
7. **CTA section** -- reuse existing CtaSection component (gold gradient, "Verbeter je bedrijfsproces vandaag nog")

### Blog Listing Page (`/blogs`)

Layout:
1. **Page title (h1)** -- "Blogs", Display size, centered
2. **Blog card grid** -- 1 column mobile, 2 columns tablet, 3 columns desktop (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6`)
3. Each card:
   - Hero image (aspect-video, rounded-t-xl, object-cover)
   - Content area with bg-white rounded-b-xl p-6
   - Date in `text-sm text-brand-gray-dark`
   - Title in `font-heading text-lg font-bold text-brand-black` (2 lines max, line-clamp-2)
   - Excerpt in `text-sm text-brand-gray-dark line-clamp-3`
   - Entire card is a clickable link with `hover:shadow-lg transition-shadow rounded-xl border border-gray-100`
4. **CTA section** -- reuse CtaSection component

### Case Study Page (`/cases/[slug]`)

Identical layout to blog post page, with these differences:
- No reading time badge
- Author row shows "Door: [Name]" only
- Hero image uses bg-brand-gold background (matching Framer pattern for case hero images)

### Case Study Listing Page (`/cases`)

Layout:
1. **Page title (h1)** -- "Cases", Display size, centered
2. **Case card grid** -- 1 column mobile, 2 columns desktop (`grid-cols-1 md:grid-cols-2 gap-6`)
3. Each card:
   - Hero image (aspect-video, rounded-t-2xl, object-cover, bg-brand-gold if no image)
   - Content area: rounded-b-2xl p-6
   - Title in `font-heading text-lg md:text-xl font-bold text-brand-black`
   - Entire card is a clickable link with `hover:shadow-lg transition-shadow rounded-2xl overflow-hidden`
4. **CTA section** -- reuse CtaSection component

### Service Page (`/automation`, `/data-verrijking`, `/api`, `/maatwerk-software`, `/offerte-automatisering`, `/ai-agent`, `/chatbot`)

Layout from top to bottom (matching Framer service page pattern):
1. **Hero section** -- bg-brand-gold gradient-to-b to brand-white
   - h1 title: Display size, centered
   - Subtitle paragraph: `text-lg md:text-xl text-brand-gray-dark max-w-2xl mx-auto text-center`
2. **Value proposition section** -- bg-white
   - h2 heading + body text describing the service
   - Optional image or illustration alongside text (lg:grid-cols-2 layout)
3. **How-it-works / features section** -- bg-brand-gray-light
   - h2 heading centered
   - Feature cards in grid (1-2 columns), each with accent background color, rounded-2xl, p-8
4. **Practical examples section** -- bg-white
   - h2 heading
   - Problem/solution pairs styled as cards or list items
5. **Mini CTA / inquiry block** -- bg-brand-gold rounded-2xl p-8, centered
   - h4 heading: "Nieuwsgierig? We vertellen je graag meer!"
   - Button link to /contact
6. **Testimonials section** -- reuse TestimonialsSection component from homepage
7. **FAQ section** -- bg-brand-gray-light
   - h2 "Veelgestelde vragen"
   - Accordion items: question in `font-heading font-bold text-brand-black`, answer in `text-brand-gray-dark leading-relaxed`
   - Accordion toggle: chevron icon, smooth open/close animation (max-height transition, 300ms ease)
8. **CTA section** -- reuse CtaSection component

### About Page (`/over-ons`)

Layout:
1. **Hero section** -- bg-white
   - h1 "Over HoneyLink", Display size, centered
2. **Mission section** -- bg-white, lg:grid-cols-2
   - Left: h2 mission heading + body paragraphs
   - Right: team photo, rounded-2xl
3. **Team section** -- bg-white
   - h2 "De bezige bijen van HoneyLink", centered
   - Team member cards in grid (1 column mobile, 2 columns desktop)
   - Each card: photo (rounded-2xl, aspect-square object-cover), name in `font-heading font-bold`, role in `text-sm text-brand-gray-dark`
4. **FAQ section** -- same pattern as service pages
5. **CTA section** -- reuse CtaSection component

### Legal Pages (`/terms-conditions`, `/betalings-voorwaarden`, `/privacy-policy`)

Layout:
1. **Header** -- bg-white, centered
   - h1 page title, Display size, centered
   - Optional "Last Updated: [date]" in `text-sm text-brand-gray-dark text-center`
2. **Prose body** -- max-w-4xl mx-auto, rendered from Markdown, standard prose typography
3. No CTA section (legal pages do not include the gold CTA block, matching Framer)
4. No hero image

## Interaction Patterns

### FAQ Accordion

- **Default state:** All items collapsed
- **Toggle:** Click on question row toggles that item open/closed
- **Animation:** Chevron rotates 180deg (rotate-180), content slides open with max-height transition (300ms ease-out)
- **Multiple open:** Allow multiple items to be open simultaneously (not exclusive accordion)
- **Keyboard:** Enter/Space toggles the focused item
- **ARIA:** `button` with `aria-expanded`, `aria-controls` pointing to the answer `div` with `role="region"`

### Blog/Case Card Hover

- **Default:** `shadow-none` or `shadow-sm`, border border-gray-100
- **Hover:** `shadow-lg`, 200ms transition
- **No color shift** -- only shadow changes
- **Entire card is wrapped in an `<a>` tag** for full clickable area

### In-View Animation

- Reuse existing `inview` action from Phase 1 (`src/lib/actions/inview.ts`)
- Apply to major section containers on service, about, and listing pages
- Classes: `opacity-0 translate-y-4 transition-all duration-700 ease-out [&.in-view]:opacity-100 [&.in-view]:translate-y-0`

### Prose Link Behavior

- Underlined by default
- Color: brand-purple
- Hover: brand-black
- External links: open in new tab (`target="_blank" rel="noopener noreferrer"`)
