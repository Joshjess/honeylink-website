    Create 7 service page route components. All follow the SAME layout pattern per the UI spec Service Page template. The only difference is which data file is imported.

    **Template for each `+page.svelte`:**
    ```svelte
    <script lang="ts">
      import { pageData } from '$lib/data/services/[slug]';
      import PageHero from '$lib/components/ui/PageHero.svelte';
      import ServiceFeatureCard from '$lib/components/services/ServiceFeatureCard.svelte';
      import FaqAccordion from '$lib/components/ui/FaqAccordion.svelte';
      import TestimonialsSection from '$lib/components/homepage/TestimonialsSection.svelte';
      import CtaSection from '$lib/components/homepage/CtaSection.svelte';
      import Button from '$lib/components/ui/Button.svelte';
      import { inview } from '$lib/actions/inview';
    </script>
    ```

    **Layout sections** (top to bottom, per UI spec):

    1. **Hero section** -- `<PageHero title={pageData.title} subtitle={pageData.subtitle} goldBackground={true} />`

    2. **Value proposition section** -- bg-white, `use:inview` with animation classes
       - Container: `mx-auto max-w-7xl px-4 py-16 md:py-24`
       - For the first section where `type === 'value-proposition'`:
         - If section has image: `lg:grid lg:grid-cols-2 lg:gap-12 lg:items-center`
           - Left: h2 in `font-heading text-3xl md:text-4xl lg:text-5xl font-bold text-brand-black mb-6`, body in `text-lg text-brand-gray-dark leading-relaxed`
           - Right: `<img src={section.image} class="rounded-2xl w-full h-auto" />`
         - If no image: single column with h2 + body text

    3. **Features/How-it-works section** -- bg-brand-gray-light, `use:inview`
       - Container: `mx-auto max-w-7xl px-4 py-16 md:py-24`
       - For the section where `type === 'features'`:
         - h2 centered: `font-heading text-3xl md:text-4xl lg:text-5xl font-bold text-center mb-12 text-brand-black`
         - Optional intro body text: `text-lg text-brand-gray-dark text-center max-w-3xl mx-auto mb-12`
         - Grid: `grid grid-cols-1 md:grid-cols-2 gap-6`
         - Each item: `<ServiceFeatureCard title={item.title} description={item.description} accentColor={item.accentColor} />`

    4. **Practical examples section** -- bg-white, `use:inview`
       - Container: `mx-auto max-w-7xl px-4 py-16 md:py-24`
       - For the section where `type === 'examples'`:
         - h2: `font-heading text-3xl md:text-4xl lg:text-5xl font-bold text-brand-black mb-8`
         - Body text or items rendered as cards/list items
         - If section has items: each item as a card with title in `font-heading font-bold text-brand-black mb-2` and description in `text-brand-gray-dark leading-relaxed`

    5. **Mini CTA block** -- `use:inview`
       - Container: `mx-auto max-w-3xl px-4 py-8`
       - Inner: `bg-brand-gold rounded-2xl p-8 text-center`
       - h4: `font-heading text-xl md:text-2xl font-bold text-brand-black mb-4` with text "Nieuwsgierig? We vertellen je graag meer!"
       - Button: `<Button href="/contact" variant="primary" size="md">Neem contact op</Button>`

    6. **Testimonials section** -- `<TestimonialsSection />`

    7. **FAQ section** -- `<FaqAccordion items={pageData.faq} />`

    8. **CTA section** -- `<CtaSection />`

    Apply `use:inview` with `class="opacity-0 translate-y-4 transition-all duration-700 ease-out [&.in-view]:opacity-100 [&.in-view]:translate-y-0"` on sections 2, 3, 4, and 5 (not on reused components that handle their own animation).
